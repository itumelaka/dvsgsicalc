# Manual Ringkas Pengguna — Pegawai Lapangan

1. Buka https://itumelaka.github.io/dvsgsicalc/ di Chrome/Edge/Safari.
2. Isikan ID ayam, baka, umur (bulan), tarikh pemeriksaan, pegawai dan lokasi.
3. Masukkan berat badan, testis kiri dan kanan dalam **gram**.
4. Lihat GSI (%) dan jumlah testis yang dikira automatik.
5. Gunakan butang **Simpan Rekod** untuk sejarah pada peranti ini.
6. Gunakan **Eksport CSV** untuk analisis dalam Excel dan sandaran.
7. Pilih **Cetak / PDF** untuk dialog cetakan.
8. Gunakan **Reset** untuk kosongkan butiran bagi pemeriksaan seterusnya.

### Pasang PWA
Android: Chrome → menu → **Install app** atau **Add to Home screen**. iPhone: Safari → Share → **Add to Home Screen**. Pastikan aplikasi dibuka ketika online dahulu; kemudian boleh cuba semula secara offline.

### Perhatian
- Data localStorage tidak diselaraskan ke peranti lain dan boleh hilang jika cache/storan pelayar dipadam.
- Jangan simpan rekod kerja sensitif pada peranti bersama tanpa kebenaran.
- Ikut SOP sampel, kebajikan haiwan dan bioselamatan.
- Label julat GSI ialah saringan sementara, **bukan diagnosis**.
