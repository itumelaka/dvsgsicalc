# Formula dan validasi GSI

**Jumlah testis (g)** = berat testis kiri (g) + berat testis kanan (g).

**GSI (%)** = jumlah testis (g) / berat badan (g) × 100.

Contoh: berat badan 2,500 g; kiri 9.2 g; kanan 8.8 g; jumlah 18.0 g; **GSI 0.72%**. “1800 gm” dalam petikan asal ialah salah taip, bukannya jumlah sebenar.

| GSI | Kategori sementara |
|---|---|
| < 0.30% | Bawah julat |
| 0.30%–1.10% | Dalam julat |
| > 1.10% | Atas julat |

Julat dicadangkan untuk jantan matang sekitar 3–4 bulan ke atas **bergantung baka**; belum disahkan sebagai ambang klinikal. **GSI tidak membuktikan penghasilan sperma, kualiti semen atau kesuburan.**

### Validasi
Semua tiga bacaan mesti ada, angka sah, berat badan > 0, berat testis ≥ 0, jumlah testis tidak melebihi berat badan. Kiraan penuh, hasil dipaparkan kepada dua tempat perpuluhan. Penimbangan gunakan gram (1 kg = 1000 g).
